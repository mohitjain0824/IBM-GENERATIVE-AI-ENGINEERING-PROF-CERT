## Naming Convention

Use this format consistently:

- Course: `C#-CourseNameNoSpaces`
- Module: `M1`, `M2`, `M3`, ...
- Lab: `lab-01-topic` or `topic-lab`

Example:

`C6-BuildingGenAIPoweredAppsWithPython/M1/image-captioning-lab/`

## Reusable Lab README Template

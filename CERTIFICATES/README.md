## Coursera Course Certificates

Store each completed course certificate PDF in the matching folder below.

### Naming format

Use this filename format for consistency:

`C#-CourseName-Coursera-Certificate.pdf`

Example:

`C6-BuildingGenAIPoweredAppsWithPython-Coursera-Certificate.pdf`

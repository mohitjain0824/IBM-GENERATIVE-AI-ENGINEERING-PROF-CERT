# 🎙️ Local-First AI Voice Assistant

A fully private, offline, and free voice assistant. This project demonstrates how to bridge browser-based audio recording with local Large Language Models (LLMs) and Speech-to-Text (STT) engines.

This project was inspired by an IBM guided project but has been re-engineered to be **100% local**, removing dependencies on paid APIs like OpenAI or IBM Cloud.

---

## 🧠 How It Works (The "Brain" & "Ears")

Unlike traditional assistants that send your voice data to the cloud, this application processes everything on your laptop:

1.  **Frontend (The Face):** A clean HTML/CSS/JS interface captures your voice using the browser's `MediaRecorder API`.
2.  **STT (The Ears):** The audio is sent to a Flask backend where **Faster-Whisper** (an optimized version of OpenAI's Whisper) transcribes the audio into text.
3.  **LLM (The Brain):** The text is sent to **Ollama**, which hosts **Llama 3** locally. It generates a concise, intelligent response.
4.  **TTS (The Voice):** The response is converted back to audio using **pyttsx3**, an offline text-to-speech library.
5.  **Feedback:** The audio is sent back to the browser and played automatically.

---

## 🛠️ Technical Stack

* **Backend:** Python 3.10+, Flask
* **AI Models:**
  * **Ollama (Llama 3):** Local Inference Engine
  * **Faster-Whisper:** High-speed Speech-to-Text
* **Frontend:** Vanilla JavaScript, HTML5 Media Devices, CSS3
* **Speech Synthesis:** pyttsx3

## 🚀 Installation & Setup

### 1. Prerequisites
* **Ollama:** Download and install from [ollama.com](https://ollama.com).
* **Python:** Ensure Python 3.10 or higher is installed.

### 2. Setup the AI Model
Open your terminal and run:
```bash
ollama run llama3
```
*Wait for the download to finish. Once you see the `>>>` prompt, Llama 3 is ready.*

### 3. Clone and Install Dependencies
```bash
# Create project folder
mkdir local-voice-assistant
cd local-voice-assistant

# Setup virtual environment
python -m venv venv
# Activate it (Windows)
.\venv\Scripts\activate
# Activate it (Mac/Linux)
source venv/bin/activate

# Install libraries
pip install flask flask-cors requests faster-whisper pyttsx3
```

---

## 🏃 Running the Application

1.  **Ensure Ollama is active** in the background.
2.  **Start the Flask Server:**
    ```bash
    python server.py
    ```
3.  **Access the Assistant:**
    Open your browser and go to `http://localhost:5000`.
4.  **Interact:**
    * Click the **"Start Recording"** button.
    * Speak your question.
    * Click **"Stop Recording"**.
    * The assistant will process and speak back to you!

---

## 🛡️ Privacy & Performance Note
* **Privacy:** No audio data or text is ever sent to a third-party server. Everything stays on your `localhost`.
* **Hardware:** This app is optimized for CPU usage using the `tiny` version of Whisper. If you have a dedicated GPU, you can modify `worker.py` to use `device="cuda"` for even faster response times.
